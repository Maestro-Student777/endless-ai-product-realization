# Endless AI Knowledge Articles

This library separates demonstrated facts, calculations, simulations, open questions, and imaginative concepts so readers can learn without confusing a possibility with a verified product.

## Article status labels

- **Established:** supported by reliable technical references or standard practice
- **Demonstrated:** reproduced in a documented experiment
- **Simulated:** works in a stated software model with explicit assumptions
- **Experimental:** plausible but requires physical testing
- **Conceptual:** imaginative direction not yet shown to be feasible
- **Not offered:** outside present legal, safety, technical, or commercial limits

## Standard article template

Every article should identify:

- What the concept is
- What is already established
- What has actually been tested
- Assumptions and limitations
- Safety boundaries
- A screen simulation or calculation, when useful
- A physical experiment, when safe and affordable
- Sources and prior art
- Possible components or suppliers
- What evidence would change the current conclusion

No article should present simulation alone as proof that a physical product is safe, compliant, manufacturable, or commercially available.
