# EAI-LAMP-0001 — Custom Wall-Plug Lamp

## Status

**Learning demonstration — not a customer order.**

## Idea

Create a creator-designed lamp that can move from a drawing or written description to a simulated circuit, manufacturable enclosure, supplier-backed bill of materials, safety review, physical prototype, and delivered product.

The 🔌 symbol represents both the literal wall connection and the point where a digital idea connects to real manufacturing.

## Desired experience

A creator should be able to:

1. Describe or sketch a lamp.
2. Select basic behavior such as on/off, dimming, pulsing, color change, music response, or sensor response.
3. Arrange understandable emoji-based modules.
4. Simulate the behavior before purchasing anything.
5. Receive an explanation of feasibility, limitations, safety considerations, estimated components, and possible manufacturing routes.
6. Approve a defined scope before physical work begins.

## Initial functional blocks

| Symbol | Block | Purpose |
|---|---|---|
| 🔌 | Input power | Connect the product to an appropriate power source |
| 🔋 | Low-voltage power | Safely power early experiments where appropriate |
| 💡 | Light output | Produce visible light |
| 🎚️ | Control | Turn on/off or adjust intensity |
| 👆 | Touch input | Respond to touch or proximity |
| 🎤 | Sound input | Respond to music or speech |
| ❤️ | Bio signal | Represent a future heartbeat-reactive input |

## Boundaries

- The first screen simulation is educational and does not certify a physical electrical product.
- Wall-powered construction must not be treated like a paper-circuit experiment.
- Mains voltage, thermal behavior, enclosure design, strain relief, insulation, component ratings, and applicable certification requirements require qualified review.
- Existing products may be purchased or modified only when legally permitted and technically appropriate.
